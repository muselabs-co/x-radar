# X Radar

[English](README.md)

一个 Chrome 扩展，用来查看谁没有回关你、你还没有回关谁，以及粉丝列表后来发生了什么变化。它使用浏览器里已经登录的 X 账号。列表和变动历史只保存在本机。

## 功能

- **未回关、单向粉丝、互相关注。** 扫描会根据你的关注和粉丝整理出这三份列表。
- **变动历史。** 之后的完整扫描会记下新粉丝和取关。在 x.com 上的关注、回关和取关，如果页面能确定是谁，也会写入历史。
- **网页过滤。** 在自己的关注页或粉丝页，可以隐藏已经互关的人。这个开关不走扫描接口。
- **语言。** 面板支持中文、英文、日语、韩语、越南语、西班牙语和葡萄牙语。浏览器语言不在其中时，使用英文。
- **侧栏或弹窗。** 浏览器支持侧栏时，标题旁的标识可以在侧栏和弹窗之间切换，并记住选择。不支持侧栏时只用弹窗，不显示切换。
- **大号。** 关注加粉丝超过 1 万时，不显示扫描区域。网页过滤仍然可用。

扩展使用原生 JavaScript，没有构建步骤，也没有运行时依赖。

## 安装

1. 打开 `chrome://extensions/`。
2. 打开**开发者模式**。
3. 选择**加载已解压的扩展程序**，选中本文件夹。
4. 把 **X Radar** 固定到工具栏。

## 使用

1. 打开并登录 [x.com](https://x.com)。
2. 从工具栏打开 X Radar。
3. 用顶部开关过滤当前关注页或粉丝页。用「打开关注页」或「打开粉丝页」跳到对应页面。
4. 如果扫描区域还在，展开「深度雷达扫描」后开始扫描。结果按页签分类，其中包含变动历史。

重新加载扩展后，请刷新已经打开的 x.com 页面，页面脚本才会更新。
